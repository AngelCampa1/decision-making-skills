\begin{abstract}
Two open-source engines, GEPA and Microsoft's SkillOpt, automatically rewrite
the markdown ``skill'' files that agent tools load, and both accept an edit on
a single unreplicated score comparison. Their evaluations, and the wider
skill-evaluation literature, lack two cheap controls: a placebo, a document of
matched length and structure whose content says nothing, and power arithmetic
computed from the design before the run. We report the first
placebo-controlled evaluation of automated skill optimisation we are aware
of, pre-registered under a gate that refuses any published run whose
prediction cannot be shown by git ancestry to predate its data.

We evolved a decision-making skill with each engine against one target model,
\NUM{\studyModel}, inside one harness, then ran seven arms across two
deterministic passes over a holdout minted after both winners were frozen:
no skill, the initial seed skill, a structure-matched placebo, two length-matched
per-winner placebos, and the two evolved winners (14,700 calls in all).
Comparisons are McNemar exact against each arm's matched placebo with Holm
correction across a family of \NUM{\familySize} per item set, on
\NUM{\unseenItems} unseen items across \NUM{\templatesUnseen} held-out
templates and \NUM{\seenItems} seen items across \NUM{\templatesSeen} trained
templates, analysed separately, backed by template-unit cluster sign-flip tests.

\textbf{No arm rejects on either item set at the pre-registered dual bar}
(Holm $q < 0.05$ and template cluster sign-flip $p < 0.0167$). SkillOpt clears the
item unit on unseen scenarios ($\NUM{\effectUnseenSkilloptVsPlaceboSkillopt}$,
raw $p = \NUM{\pUnseenSkilloptVsPlaceboSkillopt}$, Holm $q = \NUM{\qUnseenSkilloptVsPlaceboSkillopt}$)
but fails cluster sign-flip ($p = \NUM{\clusteredUnseenSkilloptVsPlaceboSkillopt} > 0.0167$).
GEPA clears the item unit on seen scenarios ($\NUM{\effectSeenGepaVsPlaceboGepa}$,
raw $p = \NUM{\pSeenGepaVsPlaceboGepa}$, Holm $q = \NUM{\qSeenGepaVsPlaceboGepa}$)
but fails cluster sign-flip ($p = \NUM{\clusteredSeenGepaVsPlaceboGepa} > 0.0167$).
Both winners had written training-item constants into their bodies; an ablation
probe confirms seen-template gains collapsed when those numbers were abstracted.
An empty prompt (\texttt{off}) beat the seed skill (\texttt{on}) by $\sim 6$--$7$
points across both sets: prompt text provoked runaway generations that reached the
output cap. Pass agreement was 100\% across all seven arms, and an A/A control
returned \NUM{\aaPairs} of \NUM{\aaPairs} identical.
Template clustering removes spurious significance from pooled item tests, and
we argue both controls belong in any skill evaluation.
\end{abstract}
